# 平面六边形棋盘原型

本原型要验证的问题是：六个同规格三角形拼成的半径 4 六边形网格，能否用统一图结构表达王、皇后、象、兵的路线，并让玩家与自动演示共用同一套合法移动算法。

当前规则假设会显示在页面右侧。它们是用于讨论的原型定义，不代表最终规则已经锁定。

“吃子演示”会载入一个专门局面，用于直接验证兵吃兵/王、象吃兵、后吃象、王吃后以及升降级结算。吃子是原地攻击，双方不会换位；防守方强制降级或死亡，符合条件的攻击方可以选择是否升级。

皇后每回合必须完整移动三步。自动演示使用三层 Minimax + Alpha-Beta 搜索，并把升级与保持原级都纳入局面评估。

运行：

```powershell
npm start
```

访问 <http://127.0.0.1:8780>。

规则层测试：

```powershell
npm test
```
